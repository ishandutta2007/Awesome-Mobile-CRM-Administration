# Awesome-Mobile-CRM-Administration

## Top Mobile CRM Administration Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Mobile Admin Consoles, On-the-Go Configuration & Field Operations Management*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Mobile CRM Administration Tools**. These tools give administrators, operations managers, and field leads the ability to manage users, monitor system health, configure settings, and handle tickets from mobile devices — without being tied to a desktop console.

**Examples** include Salesforce SalesforceA for Admins, Microsoft 365 Admin App, Google Workspace Admin App, Jamf Admin, Meraki Mobile Admin, ServiceNow Admin App, Okta Admin App, Zendesk Support App, Freshdesk Mobile Admin, and AWS Console App (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom admin workflows, and transparent administrative control — ideal for platform teams, IT administrators, and developers building data-sovereign mobile admin platforms.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce SalesforceA for Admins](https://www.salesforce.com/)**  
  Official Salesforce mobile app for administrators to manage users, reset passwords, freeze accounts, and monitor org health from anywhere.

- **[Microsoft 365 Admin App](https://www.microsoft.com/en-us/microsoft-365/business)**  
  Mobile admin app for Microsoft 365 to manage users, groups, licenses, and service health on the go.

- **[Google Workspace Admin App](https://workspace.google.com/)**  
  Mobile app for Google Workspace administrators to manage users, groups, devices, and security settings.

- **[Jamf Admin](https://www.jamf.com/)**  
  Mobile companion for Jamf Pro to manage Apple devices, users, and policies from iOS.

- **[Meraki Mobile Admin](https://meraki.cisco.com/)**  
  Cisco Meraki mobile app for network administrators to monitor devices, clients, and network health.

- **[ServiceNow Admin App](https://www.servicenow.com/)**  
  Mobile admin app for ServiceNow platform to manage users, groups, and system configuration.

- **[Okta Admin App](https://www.okta.com/)**  
  Mobile app for Okta administrators to manage users, groups, and MFA settings.

- **[Zendesk Support App](https://www.zendesk.com/)**  
  Mobile app for Zendesk administrators and agents to manage tickets, users, and support operations.

- **[Freshdesk Mobile Admin](https://www.freshworks.com/freshdesk/)**  
  Mobile app for Freshdesk administrators to manage tickets, agents, and support settings.

- **[AWS Console App](https://aws.amazon.com/console/)**  
  Mobile app for AWS administrators to monitor resources, view alarms, and manage cloud services.

## Open-Source GitHub Projects

- **[BottleCRM](https://github.com/Django-CRM/Django-CRM)**  
  Open-source multi-tenant CRM with native Flutter mobile app (iOS + Android) for admin and operational workflows. PostgreSQL Row-Level Security for tenant isolation, helpdesk with SLA timers, REST API with OpenAPI schema for agent access. MIT licensed [citation:10].

- **[FreeScout](https://github.com/freescout-helpdesk/freescout)**  
  Open-source helpdesk and shared mailbox built with PHP/Laravel, with mobile apps for Android and iOS. Administrators can manage tickets, users, and knowledge base from mobile. AGPL-3.0 licensed [citation:5][citation:16].

- **[Faveo Helpdesk](https://github.com/ladybirdweb/faveo-helpdesk)**  
  Open-source helpdesk and support ticketing system built on Laravel with free Community Edition mobile apps for Android and iOS. Admin features include ticket management, user administration, and workflow configuration [citation:11].

- **[Kubenav](https://github.com/kubenav/kubenav)**  
  Open-source mobile app for Kubernetes cluster administration. View resources, manage workloads, check logs, and scale deployments from iOS or Android. Built with Flutter and Go [citation:17].

- **[K8Z](https://github.com/k8zdev/k8z)**  
  Lightweight open-source mobile and desktop application for Kubernetes management. Provides cluster metrics, resource overviews, log viewing, and container shell access. Includes Pro tier with in-app purchases [citation:6][citation:12].

- **[Pi Stats Mobile](https://github.com/ferbruary/PiStats)**  
  Open-source iOS app for Pi-hole network administration. Monitor ad-blocking stats, enable/disable blocking, manage domain lists, and view query logs. 100% open source, no data collection [citation:3][citation:9].

- **[Pi-hole Client](https://github.com/tsutsu3/pi-hole-client)**  
  Open-source Android app for Pi-hole server management. View statistics, enable/disable server, manage domain lists, and access logs. Supports Pi-hole v6. Apache 2.0 licensed [citation:19].

- **[EspoCRM Mobile](https://github.com/espocrm/espocrm)**  
  Open-source CRM with native iPhone app for pipeline management, calling, texting, and push notifications. Same admin account and data as desktop portal.

- **[SuiteCRM Mobile](https://github.com/salesagility/SuiteCRM)**  
  Community mobile companion apps for SuiteCRM with real-time access to Accounts, Contacts, Leads, and Opportunities. Offline mode with queued updates and REST API sync.

- **[CustomerDB-Android](https://github.com/schorschii/customerdb-android)**  
  Open-source Android app for managing customers, appointments, and vouchers. Self-hosted sync server available, no forced cloud connection, no tracking. Also available for iOS [citation:15].

- **[XERP](https://github.com/XERP)**  
  Open-source business solution with CRM, sales, accounting, project, HR, and stock modules. Mobile admin access for business operations management. No data collection [citation:4].

- **[Demo-MultiRoleApp](https://github.com/coderooz/Demo-MultiRoleApp)**  
  Open-source React Native/Expo reference app demonstrating role-based admin, editor, and viewer interfaces. Useful blueprint for building custom mobile admin consoles with role-specific UI [citation:18].

- **[sub2api-mobile](https://github.com/ckken/sub2api-mobile)**  
  Mobile-first admin console built with Expo + React Native for Sub2API operations. Features server health monitoring, user/API key management, multi-account switching, and secure storage semantics. MIT licensed [citation:1].

- **[lacarotte-admin](https://github.com/lacarotte-admin)**  
  Open-source admin panel built with Expo and React for the La Carotte platform. Cross-platform (iOS, Android, Web) with REST API communication [citation:7].

### Additional Strong Open-Source Options

- **[pfDroid](https://github.com/CharlieMarshall/pfDroid)** — Open-source Android app for pfSense firewall configuration and administration (archived but functional reference) [citation:8].
- **[NEXT FAS](https://www.rapidnative.com/project/public/ebhWDIXiUlPuIFqonAb_f)** — React Native mobile app for monitoring Proxmox servers and pfSense firewalls with distinct admin/client interfaces [citation:2].
- **[YouCRM for SuiteCRM](https://play.google.com/store/apps/details?id=com.youaddon.suitecrmmobilev2)** — Companion mobile app for SuiteCRM via REST API with record management and admin activity tracking.
- **Mobile Frameworks** — Flutter, React Native, and Expo for building custom cross-platform admin apps.
- **Role-Based Access Control** — Keycloak, Casbin, and OpenFGA for mobile admin permission management.
- **Push Notification Infrastructure** — Firebase Cloud Messaging, OneSignal for admin alerts and system notifications.

**Frameworks for building custom systems**: Combine **BottleCRM** or **EspoCRM** for CRM backend, **FreeScout** or **Faveo** for helpdesk admin, **Kubenav** or **K8Z** for infrastructure administration, and **Flutter** or **React Native** for cross-platform mobile admin apps.
